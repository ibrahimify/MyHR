# Documentation Archive

This directory preserves useful history while keeping current documentation readable.

| Folder | Contents | Why archived |
| --- | --- | --- |
| `product-planning/` | Launch audit and thesis completion plan | Milestone plans are substantially completed or superseded by current scope and roadmap documents |
| `project-lab/` | Early report, presentations, rendered PDF guides, and progress page | Historical project-lab deliverables; editable current guides remain in `docs/guides/` |
| `research-audits/` | Dated early research and methodology audits | Findings are preserved, but later independent review and corrected report supersede their status summaries |
| `research-plans/` | Initial research implementation plan | Implementation has progressed beyond this plan |

Archived documents are evidence of project evolution. Do not silently rewrite them to match later conclusions. When citing a result or decision, prefer `docs/README.md` and the current authority documents it identifies.
