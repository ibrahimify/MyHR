# TDK paper tables

Each `.tex` file is a complete `table` float generated by
`python scripts/build_tdk_figures.py`. Do not edit them by hand; change the
generator and rebuild.

Required preamble:

```latex
\usepackage{booktabs} % \toprule, \midrule, \bottomrule, \addlinespace
\usepackage{array}    % >{\raggedright\arraybackslash}p{...} in abstract_commitments.tex
```

Include a table with `\input{docs/tables/residual_equal_budget.tex}`.

| File | Content | Source |
| --- | --- | --- |
| `residual_equal_budget.tex` | Section 6.7 equal-budget residual table | `research_outputs/independent_development/independent_development_4feea4508de1bb05/aggregate_metrics.csv` |
| `rules_outcomes.tex` | Deterministic check outcomes | same artifact, `operating_point == rules_fixed` |
| `demo_outcomes.tex` | In-app demonstration output. This is not experimental evidence. | `%LOCALAPPDATA%/Temp/myhr_drive/demo_counts.json` |
| `abstract_commitments.tex` | Mirrors the Section 1.6 table of `docs/TDK_PAPER_DRAFT.md` | parsed from the paper draft at build time |

The column widths in `abstract_commitments.tex` (4.3 + 2.7 + 6.0 cm) fit a
14 cm text block (A4 with 3.5 cm margins). Source checksums for every table are
listed in `docs/figures/FIGURE_MANIFEST.json`.
