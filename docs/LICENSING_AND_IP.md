# Licensing And IP Decision Note

No permissive open-source license has been added yet.

This is intentional. MyHR is connected to a BSc thesis and TDK research project, and licensing should be chosen only after considering supervisor guidance, university expectations, publication plans, and possible future commercialization.

## Current Practical Meaning

Without a license file, others may view the public repository under GitHub's terms, but they do not automatically receive broad permission to copy, modify, redistribute, or commercialize the project.

## Common Future Options

| Option | When It Fits | Tradeoff |
|---|---|---|
| MIT License | Maximum adoption, easy for others to use, good for stars and portfolio visibility. | Gives broad reuse rights with minimal restrictions. |
| Apache-2.0 | Similar to MIT but includes explicit patent language. | Slightly longer and more formal. |
| GPL-3.0 | Keeps derivatives open source. | Less attractive for commercial adopters. |
| Proprietary / All Rights Reserved | Best if commercialization or IP protection is the priority. | Reduces outside adoption and contributions. |
| Delayed license | Useful until thesis/TDK/IP decisions are settled. | Public viewers may hesitate to use or contribute. |

## Recommendation

For now, keep the repository public for portfolio visibility but do not add a permissive license until the supervisor/IP position is clear.

If the goal later becomes maximum GitHub adoption and stars, MIT or Apache-2.0 would be the most approachable choices.
